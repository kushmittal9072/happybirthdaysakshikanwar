## ✨ Features Included:

1. **🌌 3D Interactive Universe**:
   - Three.js particle starfield, floating 3D extruded hearts, falling rose petals, and dynamic light following your cursor.

2. **📸 3D Photo Realm (Non-Standard Creative Display)**:
   - **3D Revolving Cylinder**: Smooth 3D circular rotating carousel featuring all 5 uploaded photos of Sakshi with drag, swipe, next/previous buttons, and auto-spin.

3. **💍 Interactive Proposal Arena ("Will You Marry Me?")**:
   - **Runaway "No" Button**: Intelligently dodges mouse hover and touch on mobile within proximity with hilarious and sweet dialogues (*"Arey! Pakad ke dikhao pehle 😜"*, *"Destiny says YES! 💍✨"*).
   - **Pulsating "YES" Button**: Triggers multi-stage 3D confetti blasts, fireworks, celebration fanfare, and opens celebratory modal.

4. **🎂 Virtual Birthday Cake & Candle Blowout**:
   - Realistic layered virtual cake with 21 glowing candles that can be blown out by clicking or tapping "Blow Out Candles 💨", revealing customized birthday wishes.

5. **📜 Love Shayari Sanctuary**:
   - 6 Heartfelt Hindi & English Shayaris specifically dedicated to Sakshi Kanwar, with copy buttons and heart like counter.

6. **🎵 Built-in Romantic Piano Music Synthesizer**:
   - Real-time Web Audio API romantic melody generator with equalizer visualizer and play/pause controls.

2. **Option B (Directly from Terminal)**:

## 🚀 How to Run the Website:

- Simply double-click `index.html` to open it directly in any browser (Chrome, Edge, Firefox, Safari)!
- Or run a local live server:
  ```powershell
  python -m http.server 8000
  ```
  Then open `http://localhost:8000` in your browser.
